# Showcase production

The included recorder captures the live application at 100,000 strands, with
the published showcase settings documented in README. All 12 ten-second chapters
include on-screen explanations. The final MP4 is a transcode of real-time WebM
capture, with no frame interpolation or playback speed change.

Source provenance: MakeHuman CC0 anatomical assets; original application and
deformation/material code; MIT CUDA WebShader compiler/runtime.
